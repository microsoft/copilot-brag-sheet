Set up once

Requires Node.js 22+ and the GitHub Copilot CLI with an active Copilot subscription. Use a current CLI with experimental extension support. No npm install or separate plugin account is needed.

GitHub-backed plugin Recommended

Installs current code from GitHub. Run in PowerShell, macOS Terminal, or a Linux shell.

copilot plugin marketplace add microsoft/copilot-brag-sheet
copilot plugin install copilot-brag-sheet@brag-sheet
copilot config experimental on
copilot

The third command is a one-time opt-in to experimental features for this Copilot profile, not just brag-sheet. Follow your organization's policy. After that, launch normally with copilot. Prefer session-only activation? Skip the third command and launch with copilot --experimental instead.

Approve the extension's hooks when prompted. Open /extensions manage and confirm copilot-brag-sheet is running before relying on capture. The extension API is experimental; behavior can vary by CLI version and launch mode.

Already using the older installer? Close your CLI sessions and move the old copilot-brag-sheet folder out of your Copilot home's extensions directory. Keep it as a fallback; do not run both copies. Leave your separate work-data directory untouched. Install into the same CLI profile you use for work.

Need another installation method? See the alternative installers (Bash or PowerShell), npm installation for versioned releases, and the troubleshooting guide. Marketplace installs follow the current branch; npm installs use the latest published release.

Want your agent to handle setup? Use the installation prompt, then restart and verify the extension.

Update or remove the plugin

Refresh the marketplace and plugin, then restart Copilot CLI:

copilot plugin marketplace update brag-sheet
copilot plugin update copilot-brag-sheet@brag-sheet

To remove it, run copilot plugin uninstall copilot-brag-sheet@brag-sheet. Your saved records are stored separately; uninstalling the plugin does not remove them.

Three useful things to ask

Save a short note when you finish something worth remembering. Include the result and a source link you are allowed to retain. Later, review the notes or export them.

  • brag — here's what changed and why
  • review my last two weeks
  • generate work log

Records live in your OS app-data directory as structured JSON. Work outside the active CLI session is not captured automatically: add it manually or explicitly request a scoped backfill. File counts alone are not accomplishments.

Turn your notes into a first draft

Agree on the review period, then ask Copilot:

Draft a short review from my saved entries for this period. Group related work, cite the sources, and flag anything missing. Keep my contribution separate from team outcomes. Do not invent metrics. Show me the draft before sharing it.

Review the dates and sources, remove sensitive details, and edit the draft in your own voice. The plugin provides records and a generated work log; your AI host helps write the narrative.

Where your information goes

The plugin stores records on your machine and emits no telemetry of its own. That does not make AI processing offline or make every backup destination appropriate.

  • Use an approved host and account. Review tools return saved content to your AI host. Follow your organization's rules for the information you process.
  • Keep secrets out. Do not include credentials, raw customer data, or unnecessary sensitive details. Formatting sanitization is not secret redaction.
  • Leave git backup off unless approved. Backup is optional. A private personal repository is not automatically a suitable destination for employer information.
  • Inspect before sharing. Check generated logs and drafts. Use synthetic data in demos, screenshots, and public issues.

Capture depends on the experimental host API and can be incomplete. Check session records and capture counters rather than assuming every action was recorded. The isolated setup check shows how to verify capture without putting test entries in your real history. See the security model and limitations.
